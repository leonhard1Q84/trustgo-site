# TrustGo 品牌素材

来源：[TrustGo Figma UI](https://www.figma.com/design/iFvRMw5bmLZLhwegZB4qtK/TrustGo?node-id=1-1824)。同步日期：2026-11-17。

| 素材 | 来源与用途 |
| --- | --- |
| `trustgo-logo.svg` | 节点 `1:1824` 原始导出，包含手写 TrustGo 与 Car Rental；供共享 `BrandLogo` 使用，保持原始比例与颜色。 |
| `trustgo-icon.png` | 用户于 2026-11-17 提供并确认的 800 × 800 蓝底白色手写 TG 原图，用于小尺寸图标。 |
| `trustgo-logo.png` | 完整 SVG 的 1024 × 1024 白底居中版本，用于社交分享与结构化数据；`src/assets/brand/trustgo-logo.png` 保持相同内容。 |
| `/icon.png`、`/apple-icon.png` | TG 原图等比例缩小，分别为 512 × 512、180 × 180，不增加留白或改变配色。 |
| `/favicon.ico`、`/favicon-16x16.png`、`/favicon-32x32.png`、`icon-full-32.png` | 同一 TG 原图的小尺寸版本；ICO 包含 16、32、48px。 |

SVG 必须来自设计稿原始导出，不手绘路径或用字体替代。品牌图形的固有颜色不用于替换全站交互色 token。
