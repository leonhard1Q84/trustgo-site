# 查单入口静默会话检查

日期：2026-10-28。浏览器交互、PC / Tablet / H5 与多语言验收均待人工确认。

| 场景 | 当前行为 |
| --- | --- |
| 点击全站 Find my bookings | 服务端通过 HttpOnly Cookie 确认账户与访客授权；等待期间保持原页面，不打开查单弹窗、遮罩或校验骨架屏 |
| 有效 guest session 或已登录 | 直接进入订单列表；已登录但无订单仍进入列表空状态，不依据前端账户缓存跳过服务端判断 |
| 没有有效授权 | 服务端确认后才打开原有查单表单；用户主动查询其他确认号时仍直接打开表单 |
| 请求异常 | 显示现有错误与重试入口，不把服务失败当成未授权或空列表 |
| 重复点击与过期响应 | 检查期间合并重复入口点击；页面切换或主动打开其他查单后，旧响应不能关闭新表单或触发导航 |
