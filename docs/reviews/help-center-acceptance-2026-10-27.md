# 帮助中心重构验收 · 2026-10-27

## 实现范围

按参考图的信息与交互结构，提供居中搜索、四个快捷入口、六个租车阶段分类、对应主题入口及底部联系支持区。沿用 TrustGo 中性色与品牌主操作，不复制参考站点的业务承诺。保留现有九个问答主题及文章 URL，复用原有问答、宠物旅行指南与五语言内容。

- Desktop：左侧阶段分类、右侧主题入口；Tablet / H5：横向可滚动分类，主题自然换行。
- 搜索：输入后点击搜索或按 Enter，匹配全部主题、关键词、问题和答案；结果可展开，文章链接可直达问题。清除／浏览分类恢复之前选中的阶段。
- 快捷入口：查找预订、取消说明、道路救援说明、收据与账单说明。
- 联系入口：现有客户服务页、还车门店失物指引及邮件渠道；不增加在线修改、工单或新聊天系统。
- 搜索原文仅保存在当前页面内存中，不进入 URL 或浏览器持久化。
- 新增共享 Radix Tabs 原语；帮助中心标题移除重复的 TrustGo 品牌后缀。
