# 登录账户订单入口修复验收

日期：2026-10-28。PC、Tablet、H5 与多语言浏览器交互均待人工确认。

## 行为

| 场景 | 预期结果 |
| --- | --- |
| 账户页的订单与预订记录 | 直接导航至 `/{lang}/manage-booking/orders`，不绕行首页或弹访客查单 |
| 已登录账户使用全站查单入口／直接访问 `/manage-booking` | 进入订单列表，服务端读取账户归属和当前会话授权的预订 |
| 已登录但没有订单 | 展示现有列表空状态；邮箱未验证不影响已建立的登录态 |
| 删除或过期访客 Cookie，但账户仍登录 | 账户订单继续可见；失去访客授权的其他预订不再展示 |
| 切换账户／退出登录 | 隐藏旧账户列表后重新读取；旧请求不能写回旧账户数据；未登录仅保留当前会话有权访问的订单 |
| 未登录且无访客授权 | 原页打开确认号与姓氏弹窗；直接访问无授权列表时沿用既有恢复入口 |
| 查询其他确认号 | 用户主动打开访客查单，逐笔增加会话授权，不按邮箱匹配或隐式关联账户 |
| 恢复详情／结算 | 仅恢复服务端确认有访问权限、语言及确认号匹配的目标 |

本记录补充并更新 `guest-booking-session-acceptance-2026-10-28.md` 中关于已登录账户和列表范围的行为；访客授权仍有独立隔离的查询接口。
