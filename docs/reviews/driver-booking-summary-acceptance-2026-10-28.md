# 驾驶人信息页摘要与结算恢复验证

日期：2026-10-28。范围：TrustGo；IX OFFICIAL SITE 仅作为实现参考。

## 实现

- 驾驶人信息页默认收起整组费用明细，保留车辆、保障、取还车门店／时间、支付拆分、总价、含税说明及押金；门店指引仍可打开。
- 预订级失败在主操作附近显示原因及恢复入口；资料校验定位实际错误字段。
- 同一报价、驾驶人、保障、设备及建账选择完全一致的有效待付款预订可恢复原结算。其他冲突提供现有待付款预订的付款入口及预订列表入口，不覆盖旧预订资料。
- PC 与手机提交按钮显式关联同一表单；手机输入期间隐藏吸底栏，并保留表单底部提交入口和页面底部安全留白。
- 手机价格明细按钮明确为非提交按钮，展开费用不会触发预订。
