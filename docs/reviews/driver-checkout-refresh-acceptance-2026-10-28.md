## 行为

| 条件 | 预期结果 |
| --- | --- |
| 报价有效、驾照签发国未变、资料有效 | 直接创建预订并进入结算，无重新查价回跳 |
| 仅国家显示名称与代码表示不同 | 仍视为同一国家，显示与提交一致 |
| 驾照签发国实际改变 | 提交有效资料后，以新国家重新查询所选车辆费率；保留行程、保障及设备，不创建旧报价预订 |
| 报价到期 | 提示重新整理费率，只提供一个刷新操作，不展示内部流程说明 |
| 服务端确认报价失效或车辆不可用 | 阻止创建预订，进入现有刷新处理 |
