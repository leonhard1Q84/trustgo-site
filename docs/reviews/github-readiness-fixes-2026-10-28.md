## 保留边界

用户确认暂时接受账户、预订、支付与退款的本地模拟实现；既有生产保护继续保留，模拟能力不作为真实收款或正式运营交付。

当前运行框架仍为 Next.js 15.5.28，而项目规则目标为 Next.js 16；ESLint 配套为 16。本次未进行大版本迁移。多根布局的全局 404 使用 Next.js 的 experimental.globalNotFound。68 个 lint 警告、真实服务接入和上述人工点击项仍需后续确认。

仓库目前没有提交和 remote。代码可作为本地原型基线准备入库；若公开仓库，README、AGENTS.md 及内部文档的披露范围仍需由项目所有者确定。
