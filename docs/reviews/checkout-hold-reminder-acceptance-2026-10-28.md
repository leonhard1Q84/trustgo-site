## 自动检查范围

- `npm run check:i18n`：包含新 checkout 目录文案的五语言完整性检查。
- `npm run test:rental-business`：真实领域逻辑与 Route Handler 的保留过滤、绝对到期时间、会话隔离、最小摘要、不创建匿名 Cookie、未付款零退款取消、取消后不可付款等验证；不启动浏览器或发出网络请求。
- `npm run build`：生产编译、类型及项目内置 lint；另检查最终服务端构建产物中的根 metadata，确认已删除 FleetEdge 网络描述。
- `npm run preview`：复用本目录既有健康开发服务，仅确认 HTTP 和首页内容，不代表表单、响应式或租车链路已验收。
