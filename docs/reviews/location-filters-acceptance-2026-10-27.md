# 门店目的地选择与筛选验收 · 2026-10-27

对齐 IX OFFICIAL SITE 的国家／地区分组城市选择与门店服务筛选逻辑。TrustGo 门店目的地与取还车地点浏览复用 `GroupedOptionList`：中性色分组标题、无边框城市文字选项，取消逐项门店数量；仅 Hover、键盘焦点及当前选中项有轻量反馈。目的地选城市后立即筛选并关闭；取还车地点选城市后仍进入该城市的地点列表。

城市名称沿用既有业务服务区域，例如“桃園／臺北”，不新增城市或扩大服务范围。筛选仅保存在页面内存，搜索词不进入 URL 或持久化。
