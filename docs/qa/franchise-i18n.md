# 加盟商页面多语言修复验证

日期：2026-10-28。

## 修复范围

首屏说明、统计标签、仪表盘说明、系统网络标题与中心标签、申请表单的车队规模与车辆单位、备注提示、成功反馈的复制操作，以及弹窗关闭和微信号的无障碍文案，统一使用现有五语言翻译入口。数字与百分比按当前语言格式化。品牌与平台名称保留原名。

车队规模使用稳定的选项标识，提交时组合对应语言的说明；切换或取消选项不会改写用户备注，也不再依赖中文“台”的正则。接收服务不可用时显示对应语言的提示并保留输入。

| `npm run check:build` | 通过 |

| `node scripts/test-franchise-i18n.cjs --build` | 五语言页面、表单、数字格式、选项切换/取消、备注保留、提交语言、不可用及成功反馈通过；同时检查最终 HTML 的唯一 H1 / title、description、canonical、六项 hreflang 和 robots |

表单测试仅替换 React 状态容器、装饰图标和网络传输，不向外部发送咨询。静态渲染与 HTTP 健康检查不代表浏览器验收完成。
